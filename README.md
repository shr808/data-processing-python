# Data Processing with Python

This repository contains small, focused Python scripts demonstrating
common data cleaning, validation, and integration tasks.

These patterns are frequently used in internal tools, reporting pipelines,
and administrative or academic systems.

## Included Examples

### `clean_names.py`
- Normalizes personal names
- Removes extra whitespace
- Applies consistent capitalization

### `format_phones.py`
- Standardizes phone numbers
- Removes non-numeric characters
- Demonstrates regex-based cleaning

### `remove_duplicates.py`
- Identifies duplicate records
- Deduplicates based on a unique key
- Uses efficient data structures

### `validate_emails.py`
- Performs basic email format validation
- Prevents invalid user input
- Common in form and registration systems

### `merge_data.py`
- Merges records from multiple data sources
- Resolves overlapping fields
- Demonstrates data integration logic

## Notes
These scripts are intentionally simple and readable.
They represent real-world patterns abstracted from
enterprise and internal system workflows.
